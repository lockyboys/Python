# Python 학습 저장소

파이썬을 공부하며 작성한 예제와 실습 코드를 챕터별로 모아 둔 저장소입니다.

## 폴더 구성

코드는 학습 진도에 따라 `chapter2`부터 챕터별 폴더로 나뉘어 있습니다.
각 폴더 안에는 해당 단원에서 다룬 문법·개념을 연습한 `.py` 파일들이 들어 있습니다.

| 폴더 | 내용 |
| --- | --- |
| `chapter2` ~ `chapter10` | 기본 문법, 자료형, 제어문, 함수, 모듈 등 기초 실습 |
| `chapter11` | 파일 정리 자동화 프로젝트(이미지·문서·영상 분석, 대시보드 등) |
| `chapter12` 이후 | NumPy 등 데이터 분석 및 응용 실습 |

> 일부 폴더 이름에는 오타가 있습니다(예: `chaoter15`, `chapert17`).
> 기존 경로를 참조하는 코드가 있을 수 있어 우선 그대로 두었습니다.

## 실행 방법

각 스크립트는 독립적으로 실행할 수 있습니다.

```bash
python chapter2/예제파일.py
```

> Windows에서는 `python` 대신 `py`를 사용할 수 있습니다.
>
> ```bash
> py chapter2/예제파일.py
> ```

## 요구 사항

- Python 3.x
- 일부 챕터(예: `chapter11`, `chapter12`)는 추가 패키지가 필요합니다.
  실행 시 `ModuleNotFoundError`가 발생하면 해당 패키지를 설치하세요.

  ```bash
  py -m pip install <패키지명>
  ```
